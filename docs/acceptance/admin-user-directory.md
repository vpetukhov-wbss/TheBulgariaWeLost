# Административен списък с потребители

В **Работен панел → Потребители** администратор с актуално MFA може да филтрира по роля и статус, да търси по точен имейл и да прегледа профила с маскиран потвърден контакт. Стар запис без дата на създаване се показва без дата. Списъкът използва страници с курсор, обвързан с текущите филтри.

Angular използва SignalStore на маршрута за отговорите на списъка и детайла, състоянията при зареждане и прекъсването на остарелите заявки. Ролята и статусът се пазят в URL. Полето за имейл и приложеното търсене са локални сигнали на екрана.

NestJS проверява действителната роля и състоянието на сесията при всяка заявка. Документираните проекции връщат само полетата за преглед на профила. Достъпът, MFA, маскираният контакт и валидацията на курсора се проверяват в интеграционния сценарий в `apps/api/test/auth.e2e-spec.ts`.
