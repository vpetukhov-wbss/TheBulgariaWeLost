# Repository instructions

## Engineering workflow

Read [`CLAUDE.md`](CLAUDE.md) and the applicable files in `.claude/rules/` before editing. For .NET changes, start with [the C# rules](.claude/rules/dotnet-csharp.md) and [the async rules](.claude/rules/dotnet-async-concurrency.md). Apply the relevant procedures in `.claude/skills/` and the review criteria in `.claude/agents/`. For substantive .NET changes, use the feature and code-review procedures. Review method and constructor signatures before handing off the change, and report the checks actually run.
